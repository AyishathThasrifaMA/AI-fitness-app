# AI Fitness Coach - Next.js (Starter)

This is a starter implementation of the **AI Fitness Coach** described in your brief.
It contains:
- A Next.js (pages router) app scaffold.
- Tailwind CSS setup.
- A client-side mocked "AI plan generator" that produces personalized workout & diet plans.
- UI for listening to the plan (UI only, ElevenLabs integration placeholder).
- Image generation placeholders for exercises/meals.
- Export to PDF 


- `pages/index.js` - main app UI (form + plan viewer).
- `components/Form.js` - user input form.
- `components/PlanCard.js` - displays generated plan and export/voice/image UI.
- Tailwind + global CSS.

## How to run locally

1. Install dependencies:
   ```bash
   npm install
   ```
2.. Start dev server:
   ```bash
   npm run dev
   ```
3.. Open http://localhost:3000
